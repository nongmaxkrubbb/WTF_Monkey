# ระบบตรวจจับ "ท่ามือ" เฉพาะ (Gesture Matching)

ตรวจจับว่า "นิ้วไหนชูบ้าง" จากกล้อง ไม่ใช่แค่นับจำนวนนิ้ว (เช่น ชี้นิ้วเดียว กับ ยกโป้งเดียว คือ 1 นิ้วเหมือนกัน แต่เป็นคนละท่า) แล้วโชว์ภาพตามท่าที่ทำ

## ติดตั้ง

```bash
pip install -r requirements.txt
```

(ถ้าเจอปัญหาเรื่อง permission ให้เติม `--break-system-packages` ต่อท้ายคำสั่งได้)

## รันโปรแกรม

```bash
python finger_counter_v2.py
```

- รันครั้งแรกโปรแกรมจะดาวน์โหลดไฟล์โมเดล `hand_landmarker.task` อัตโนมัติ (~10MB, ต้องต่อเน็ต) แล้วเก็บไว้ใช้ครั้งต่อไปไม่ต้องโหลดซ้ำ
- กด **q** เพื่อออกจากโปรแกรม
- กด **s** เพื่อบันทึกภาพหน้าจอปัจจุบันลงโฟลเดอร์ `captures/`
- กด **+ / -** เพื่อปรับความไวในการตรวจจับนิ้วชู (FINGER_MARGIN)

## ใส่ภาพของคุณเอง

ใส่ไฟล์รูปลงในโฟลเดอร์ `images/` และตั้งชื่อไฟล์ตาม **ท่าทาง (slug)** ที่ต้องการ
โปรแกรมจะโหลดมาโชว์แทนภาพ placeholder อัตโนมัติ
รองรับไฟล์ `.gif` (ภาพเคลื่อนไหว), `.png`, `.jpg`, `.jpeg`, `.webp`

ตัวอย่างชื่อไฟล์ (ดูรายชื่อท่าเต็มๆ ได้ในไฟล์ `finger_counter_v2.py`):
```
images/
  fist.png        -> กำปั้น (หมัด)
  point.gif       -> ชี้นิ้วเดียว (นิ้วชี้)
  thumbs_up.jpeg  -> ยกโป้งเดียว (thumbs up)
  peace.jpg       -> สัญลักษณ์ V (ชี้+กลาง)
  open_palm.gif   -> กางมือทั้งห้านิ้ว
```

## ปรับแต่งได้ในไฟล์ finger_counter_v2.py

- `CAM_INDEX` — ถ้ามีกล้องหลายตัวและเปิดผิดตัว ลองเปลี่ยนเป็น 1, 2, ...
- `FINGER_MARGIN` — ความไวในการนับว่า "ชูนิ้ว" หรือยัง (ค่าเริ่มต้น 1.05)
- `GESTURES` — คุณสามารถเพิ่ม/ลด ท่าทางที่คุณต้องการตรวจจับได้ใน List นี้

## หลักการทำงาน

ใช้ MediaPipe HandLandmarker ตรวจจับจุดข้อต่อ 21 จุดบนมือแต่ละข้าง จากนั้นใช้วิธีเทียบ **ระยะห่างจากข้อมือ (wrist)** แทนการเทียบแกน y เพื่อให้ทนทานต่อการเอียง/หมุนมือ และจับคู่ Pattern (เช่น 1,0,0,0,0) กับท่าที่เรากำหนดไว้
